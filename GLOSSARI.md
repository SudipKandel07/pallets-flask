GLOSARIO — Vocabulario técnico


BACKLOG
Definición: Lista de todas las tareas pendientes de un proyecto, ordenadas según su prioridad.
Ejemplo: Añadimos las tareas del blog Flask al backlog.

CLON
Inglés: Clone
Definición: Copia local de un repositorio remoto que permite trabajar desde nuestro ordenador.
Ejemplo: Clonamos el repositorio de Flask en nuestro ordenador.

COMMIT
Definición: Registro de un conjunto de cambios realizados en el repositorio.
Ejemplo: Hicimos un commit después de modificar el README.

FORK
Definición: Copia de un repositorio que se crea en nuestra cuenta de GitHub para poder trabajar en él.
Ejemplo: Creamos un fork de pallets/flask.

GIT
Definición: Herramienta que permite controlar las versiones de los archivos y guardar el historial de cambios.
Ejemplo: Utilizamos Git para guardar los cambios del proyecto.

GITHUB
Definición: Plataforma en línea que permite alojar repositorios Git y colaborar en proyectos.
Ejemplo: Subimos nuestro repositorio a GitHub.

ISSUE
Definición: Elemento que representa una tarea, un error o una mejora que hay que gestionar.
Ejemplo: Creamos un issue para organizar una tarea del blog.

KANBAN
Definición: Método visual que organiza las tareas en columnas según la fase en la que se encuentran.
Ejemplo: Utilizamos Kanban para ver qué tareas están pendientes.

PULL
Definición: Descargar los cambios del repositorio remoto y fusionarlos con la rama local actual.
Ejemplo: Ejecutamos git pull para actualizar nuestro repositorio local.

PUSH
Definición: Enviar los commits locales al repositorio remoto.
Ejemplo: Ejecutamos git push para subir nuestros cambios a GitHub.

PETICIÓN DE CAMBIOS (PULL REQUEST)
Definición: Solicitud para que se revisen los cambios y se proponga incorporarlos a otro repositorio o rama.
Ejemplo: Creamos una pull request para proponer nuestros cambios al proyecto original.

SCRUM
Definición: Marco de trabajo ágil que organiza el desarrollo en ciclos cortos con objetivos concretos.
Ejemplo: Organizamos la práctica en dos sprints.

SPRINT
Definición: Periodo de tiempo limitado durante el cual se trabaja para alcanzar un objetivo.
Ejemplo: En el Sprint 1 seleccionamos las primeras tareas.

SPRINT BACKLOG
Definición: Conjunto de tareas seleccionadas para realizar durante un sprint.
Ejemplo: Colocamos las tareas del primer sprint en Sprint Backlog.

UPSTREAM
Definición: Nombre habitual del remoto que apunta al repositorio original del que procede nuestro fork.
Ejemplo: Configuramos upstream para conectarnos con pallets/flask.
